📋 STEP-BY-STEP SETUP (ONLY ONCE):

  STEP 1: Install (First time only)
  ─────────────────────────────────
  • Install Python from: https://www.python.org/downloads/
  • IMPORTANT: During install, check ✅ "Add Python to PATH"
  • Double-click SETUP.bat and wait 3 minutes

  STEP 2: Get Delta Exchange API Keys
  ────────────────────────────────────
  • Open Delta Exchange website: https://india.delta.exchange
  • Login to your account
  • Go to: Profile → Settings → API Keys → Create New Key
  • Give permission: Trading Only
  • Save the API Key and API Secret (copy them somewhere safe)

  STEP 3: Get Telegram Bot
  ─────────────────────────
  • Open Telegram app on your phone
  • Search for: @BotFather
  • Send message: /newbot
  • Follow instructions → Copy the TOKEN it gives you
  • Then search: @userinfobot → Send any message → Note your Chat ID

  STEP 4: Start the Bot
  ──────────────────────
  • Double-click START.bat
  • A browser window opens automatically
  • Enter your API Key, API Secret, Telegram Token, Chat ID
  • Click "SAVE & ACTIVATE MY BOT"
  • Check your Telegram — you'll get a confirmation message! ✅

  STEP 5: Daily Use
  ──────────────────
  • Every day just double-click START.bat
  • The bot runs automatically
  • You'll get updates on Telegram every 5 minutes
  • At 6:00 PM every day, Magic Line updates automatically

🤔 HOW IT WORKS (Simple Explanation):
  
  Every day at 6:00 PM, the bot notes the Bitcoin price.
  This becomes the "Magic Line".

  ✅ If Bitcoin price is ABOVE the Magic Line → Bot SELLS a PUT option
  ✅ If Bitcoin price is BELOW the Magic Line → Bot SELLS a CALL option

  If the trade loses 25% → Bot closes it automatically (Stop Loss)
  You get Telegram message for every trade! 📱
